## 怎么落实（分层落地与客户端协同）

### 1. 为何单装 banks.plugin 仍无法消除「掌上生活 / 买单吧 / 六大行」开屏广告（实证根因）

- **同域混装无法在 DNS 层切割**：**掌上生活**开屏配置与动态渲染走 `mlife.cmbchina.com` / `az1mbasecc.bas.cmbchina.com`（`/preCacheAdvertiseSec`）、`intellicc.bas.cmbchina.com`（`/getDynamicDataSec`）及招行 PaaS OpenAPI `mbmodule-openapi.paas.cmbchina.com`（同域承载积存金行情 `zBuyPrc`/`zSelPrc`），开屏图片与视频素材走 `res.cc.cmbimg.com` / `res.cc.cmbimg.cn`（`/fsp/File/AdPlatformPublic/`）、`s3gw.cmbimg.com` / `s3gw.cmbimg.cn`（`/mbappinitads/`）、`pic1cdn.cmbchina.com`（`/appinitads/`）与 `resource.cmbchina.com`（`/fsp/File/ClientFacePublic/`）；**买单吧**开屏/引导页与弹窗双线走 `creditcardapp.bankcomm.com` 与 `creditcardapp.bankcomm.cn`（`/mapp/common/queryGuidePageAds.do`、`getPopAds.do` / `qryPopAds.do` / `qryLaunchAds.do`），广告图走 `creditcard.bankcomm.com`（`/tfimg/public00/M00/` 与 `/tofimg/`）。这些域名同时承载登录、查账、还款或 UI 图床，DNS 层整域黑洞必致功能瘫痪；纯 DNS 唯一可安全拦截的仅 `mbads.paas.cmbchina.com` 等独立广告子域。
- **SSL Pinning + 国密校验阻断常规 MITM**：六大行与信用卡 App 普遍对核心 API 网关启用证书绑定或完整性校验（`Walvez/surge-startup-ads` 与社区长期反馈：把 `mlife.cmbchina.com` / `az1mbasecc.bas.cmbchina.com` / `mbmodule-openapi.paas.cmbchina.com` / `creditcardapp.bankcomm.com` / `creditcardapp.bankcomm.cn` / `mobilepaas.abchina.com.cn` 放进 `[MITM]` 极易触发「网络异常」「设置页打不开」或闪退）。**本插件严格保持零证书零 MITM**；同时 `preCacheAdvertiseSec` 等接口会在上一次启动把开屏图预缓存到本地沙盒。
- **其它信用卡与生活端同理（含 2024-2026 停服合并状态）**：**中国银行「缤纷生活」已于 2026-06-30 24 时停服并入「中国银行」App**、**邮储「邮储信用卡」将于 2026-11-25 24 时停服并入「邮储银行」App**、**上海银行「上银美好生活」将于 2026-11-30 24 时停服并入「上海银行」App**、**渤海银行「渤海银行信用卡」已于 2024-12-30 停服迁入「渤海银行」App**、恒丰银行「恒享生活」已合入「恒丰银行」、北京银行直销银行已并入京彩生活而**「掌上京彩」**仍在役、兴业原「好兴动」已更名为**「兴业生活」**；建行生活 `yunbusiness.ccb.com` 同域混走 `/clp_service/txCtrl?txcode=A3341A002|A006|A009`（推广/弹窗）与 `A3341A038/autoLogin`（签到/登录），所有大中银行的混装静态/业务域（如 `image2.elife.icbc.com.cn`、`yunbusiness.ccb.com`、`mbs.boc.cn`、`d.psbc.com:9091`、`image.spdbccc.com.cn`、`m.creditcard.ecitic.com`、`m.citiccardcdn.citicbank.com`、`yghsh.cebbank.com`、`static.95508.com`、`images.cib.com.cn`、`rs.creditcard.cmbc.com.cn`、`static.creditcard.hxb.com.cn`、`iobs.pingan.com.cn`）均不得凭宽泛路径/文件名正则误切图标目录（例如 `appspace-img/icon/*.png`、`/static/picture/`、`/mmc/img/`、`group1/M00/`）。完整全系对照分析见 `docs/banks-creditcard-ad-removal.md`。

### 2. Loon 主配置协同与代理检测防闪退

- 插件搭配：安装 `ads.plugin`（或 `ads-next.plugin`，二选一）+ `banks.plugin`；主配置 `[General]` 加入 `hijack-dns = *:53` 与 `domain-reject-mode = DNS`。本插件严格保持零 MITM（`enhance: null`），切勿将银行核心 API 网关写入 `[MITM]` `hostname`。
- 排查 Wi-Fi 代理残留：iOS 前往 `设置 → 无线局域网 → 当前 Wi-Fi 详情 → HTTP 代理`，确认处于 `关闭`（避免 Charles/抓包遗留的 `127.0.0.1` 触发银行检测）。
- 主配置 `skip-proxy` 直连豁免：若农行/建行/邮储/工行提示「检测到代理」，在主配置 `[General]` 的 `skip-proxy` 用英文逗号追加 `www.abchina.com.cn, msmp.abchina.com.cn, mobilepaas.abchina.com.cn, yunbusiness.ccb.com, login-service.mobile-bank.psbc.com, mobile-bank.psbc.com`（Loon 会原生合并列表，**禁写 Surge 的 `%APPEND%`**；本插件不擅自改写用户全局 `skip-proxy`）。
- 主配置 `[Rule]` 顶部按需显式直连：`DOMAIN-SUFFIX,icbc.com.cn,DIRECT`、`DOMAIN-SUFFIX,ccb.com,DIRECT`、`DOMAIN-SUFFIX,abchina.com.cn,DIRECT`、`DOMAIN-SUFFIX,boc.cn,DIRECT`、`DOMAIN-SUFFIX,bankcomm.com,DIRECT`、`DOMAIN-SUFFIX,bankcomm.cn,DIRECT`、`DOMAIN-SUFFIX,psbc.com,DIRECT`、`DOMAIN-SUFFIX,95516.com,DIRECT`、`DOMAIN-SUFFIX,cmbchina.com,DIRECT`、`DOMAIN-SUFFIX,cmbimg.com,DIRECT`、`DOMAIN-SUFFIX,cmbimg.cn,DIRECT`、`DOMAIN-SUFFIX,spdb.com.cn,DIRECT`、`DOMAIN-SUFFIX,spdbccc.com.cn,DIRECT`、`DOMAIN-SUFFIX,ecitic.com,DIRECT`、`DOMAIN-SUFFIX,cebbank.com,DIRECT`、`DOMAIN-SUFFIX,95508.com,DIRECT`、`DOMAIN-SUFFIX,cib.com.cn,DIRECT`、`DOMAIN-SUFFIX,cmbc.com.cn,DIRECT`、`DOMAIN-SUFFIX,pingan.com,DIRECT`、`DOMAIN-SUFFIX,hxb.com.cn,DIRECT`、`DOMAIN-SUFFIX,czbank.com,DIRECT`、`DOMAIN-SUFFIX,cbhb.com.cn,DIRECT`、`DOMAIN-SUFFIX,hfbank.com.cn,DIRECT`、`DOMAIN-SUFFIX,bosc.cn,DIRECT`、`DOMAIN-SUFFIX,bankofbeijing.com.cn,DIRECT`。
- 仍触发风控弹窗时的两种无感兜底：① 将 Loon 切换为纯 TUN（点击 `loon://proxymode=tun`，避免向系统注入 `NEProxySettings` HTTP 代理标记）；② 对强检 `NEVPNStatus` 的银行，在 iOS「快捷指令 → 个人自动化 → App」配置打开对应银行 App 时「立即运行」`loon://off`、关闭时自动执行 `loon://on`。（说明：`DOMAIN,msmp.abchina.com.cn,REJECT` 属社区风控偏方而非去广告，存在阻断农行安全监测的风险，本插件红线维持放行。）

### 3. 六大行 + 全国性信用卡 + 云闪付 客户端内官方降噪开关与适老化关怀模式（开屏+弹窗+营销，必做）

- **零风险首选——官方适老化版本（实测显著减少首页弹窗与开屏推广）**：各行依据适老化规范上线的版本普遍大幅隐藏或精简营销弹窗与首页推荐——**云闪付**（`首页右上角「+」→ 切换关爱版`）、**中国农业银行**（`我的 → 设置 → 标准版 / 关怀版（大字版）`）、**掌上生活**（`我的 → 设置 → 大字版 / 关爱版`，或向`小招助理`发「关爱版怎么开」一键开启）、**中国银行**（首页或`我的`搜索切换 **「岁悦长情版」（长辈版/关怀版）**）、**买单吧**（`我的 → 设置 → 切换版本 → 关怀版`）、**浦发银行**（`我的 → 设置 → 应用模式 / 版本切换 → 长辈版`）；其余大行/卡端：**工行**（`幸福生活版`）、**建行**（`左上角菜单 → 设置 → 切换到关怀模式`）、**交行**（`我的 → 设置 → 版本切换 → 关爱版`）、**邮储**（`我的 → 版本切换 / 设置 → 关怀版`）、**招行**（`长辈版`）。
- **云闪付（开屏 / 弹窗 / 营销全闭环）**：`我的 → 设置 → 隐私设置 → 个性化推荐设置`（关闭）+ `我的 → 设置 → 消息设置`（关闭营销推送）。注：`wallet.95516.com` 除开屏外还承载 `/s/wl/icon/long` 与 `(:10533)?/s/wl/icon/large/1` 悬浮/长效营销图标，但因强 SSL Pinning 及整域误伤风险（社区 issue 实证误拦可导致标准版↔关爱版切换报错、国补页面无法加载或重试风暴），禁止入 MITM 且默认关闭 `unionpay_optional`。
- **中国农业银行（含消息栏营销关闭与 CDN 误杀警示）**：双入口关闭——① `我的 → 设置 → 个性化推荐`（关闭）；② `首页 → 消息 → 右上角设置 → 优惠消息 / 服务通知`（关闭定向优惠弹窗与消息）。严禁拦截 `enjoy.cdn-static.abchina.com.cn` 与 `midc.cdn-static.abchina.com.cn`（`blackmatrix7` issue 实证导致农行页面白屏或必要组件缺失）。
- **中国银行（含原「缤纷生活」2026-06-30 已并入 + 营销短信直关）**：`我的 → 右上角设置 → 消息设置` 中分别关闭 **「营销优惠消息提醒开关」** 与 **「营销服务短信通知开关」**，并在`个性化设置`关闭个性化推荐；其 `mbs.boc.cn/ubas-mgateway-static/images/advertType/` 与核心交易共域且强固定，不可 MITM。
- **招商银行 / 掌上生活 & 交通银行 / 买单吧（开屏 / 弹窗 / 营销全闭环）**：**掌上生活**关闭 `我的 → 设置 → 隐私管理 → 个性化推荐设置` + `设置 → 消息通知/通用设置` 关闭营销推送（弹窗模块同走强 Pinning `mbmodule-openapi.paas.cmbchina.com/graphic/v2/module/graphic` 与 `mlife`，可配 `banks-mitm.plugin` 清理静态/视频开屏目录）；**招行**在 `我的 → 设置 → 安全中心 → 设备管理 → 允许个性化推荐` 关闭。**买单吧**关闭 `我的 → 消费者权益保护 → 其他授权管理`（使用过程信息与个性化推荐）+ `设置 → 消息设置/通知管理`（关闭营销推送），商业短信回复 `TD` 或致电交行信用卡热线加入营销拒收名单。
- **浦发银行（主端 + 浦大喜奔）**：**浦发银行主端**（`com.spdb.mobilebank.per`）在 `我的 → 设置 → 安全设置 → 其他管理选项 → 个性化推荐`（关闭）+ `设置 → 消息/通知设置`（关闭营销提醒）；**浦大喜奔**在 `我的 → 设置 → 用户保护中心 → 个性化推荐设置` 关闭。两端的 `lban.spdb.com.cn/mspmk-web-component/(getAdvList|prefetchAdvList).ah` 已由可选 `banks-mitm.plugin`（`cleanSpdbAds`）默认拦截，同时 `per.spdb.com.cn` / `ebank.spdb.com.cn` 维持红线保护。
- **工商银行 / 建设银行 / 邮储银行 / 其余股份制及城商行**：工行 `我的 → 设置 → 个性化设置 → 个性化推荐`；建行 `我的 → 设置 → 隐私管理 → 个性化推荐管理`（关闭个性化内容与广告推荐）；邮储（含 2026-11-25 合入的原邮储信用卡）`个性化推荐 / 菜单智能推荐` 或致电 `95580` 转人工关闭；动卡空间 `个人中心 → 设置 → 隐私设置 → 个性化广告推荐`；阳光惠生活/全民生活 `隐私管理 → 个性化推荐设置`；平安口袋银行 `授权管理 → 个性化推荐设置`；发现精彩/兴业生活/华彩生活/上海银行（含 2026-11-30 合入的原上银美好生活）/掌上京彩 在 `隐私设置/授权管理` 关闭，并同步关闭系统级「允许通知（营销类）」与「隐私与安全性 → 跟踪（ATT）/ 剪贴板权限」。

### 4. iOS 快捷指令 URL Scheme 启动与传感器防摇一摇（附冷启诚实局限）

- **iOS URL Scheme 启动局限与已核验图标列表**：新版**掌上生活**（`cmblife://`）与**买单吧**（`mdb://`）把开屏广告初始化绑定在根启动视图生命周期，因此**裸 `cmblife://` / `mdb://` 无参冷启动在新版往往已无法稳定跳过开屏**，主要对热恢复或带业务深链的 `cmblife://{funcName}?...` 等跳转仍可能直达功能页；其他已核验直达 Scheme（均剔除 `wx`/`wb` 微信微博回调协议）包括：**招行** `cmbchina://` / `cmbmobilebank://`、**工行** `com.icbc.iphoneclient://`、**工银e生活** `com.icbc.elife://`、**农行** `bankabc://`、**中行** `BOCMBCIphone://`、**建行** `ccbmobilebank://`、**建行生活** `cloudapp://`、**交行** `bocom://`、**邮储** `psbcmbank://`、**云闪付** `upwallet://`、**浦大喜奔** `spdbccc://`、**动卡空间** `citicbankdkkj://`、**阳光惠生活** `yghsh://`、**发现精彩** `credit://`、**兴业** `cibmb://`、**民生** `com.cmbc.cn.iphone://`、**华夏** `com.hx.hxbank://`、**平安口袋银行** `paesuperbank://` / `paebqw://`。

### 5. Android 无障碍（GKD）反诈风控规避
