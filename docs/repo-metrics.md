# 仓库规模（门禁复算）

> 本页只放可被机器重算的规模声明。`npm run lint` 的文档数字门禁把每个数字钉在构建器与四个审计工具自己的输出上；改数据源后这里没同步，门禁直接失败。

- 构建链：`npm run build:apps` 生成 19 个 App 插件，也就是 19 个 App 专属去广告插件，覆盖 24 个 App。
- 原生 MITM 增强层：9 个非固定 App（美团 / 闲鱼 / 起点读书 / 淘宝 / YouTube / 知乎 / 腾讯新闻 / 哔哩哔哩 / 高德地图），全部默认启用 Loon 原生 `[Rewrite]` v2 复写层并由 `[Argument]` 开关控制启停（其中起点读书在 `[Rewrite]` 层只保留请求阶段终止纯广告端点，字段级净化由脚本承担）。
- 官方文档 26 页逐页核对（`src/loon-docs/tokens.json`）。
- 广告面审计：19 类广告 × 6 族。
- 旁路审计：枚举 17 条「广告请求绕开整个插件」的路径。
- App 覆盖率审计：拿 14 家上游黑名单反查 19 个 App 插件。
- Loon 能力覆盖报表（176 条，探测真实用法；77 已用 / 36 可用未用 / 47 判死 / 12 不适用 / 4 未文档化）。
- 分页游标完整性门禁：扫 2 个净化脚本的 278 个键，比对 25 个分页字段名（第十四轮新增）。
