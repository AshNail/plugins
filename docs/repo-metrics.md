# 仓库规模（门禁复算）

> 本页只放可被机器重算的规模声明。`npm run lint` 的文档数字门禁把每个数字钉在构建器与四个审计工具自己的输出上；改数据源后这里没同步，门禁直接失败。

- 构建链：`npm run build:apps` 生成 13 个 App 插件，也就是 13 个 App 专属去广告插件，覆盖 18 个 App。
- 可选 MITM 增强层：3 个非固定 App（美团 / 闲鱼 / 起点读书）默认整段注释，启停自愿。
- 官方文档 26 页逐页核对（`src/loon-docs/tokens.json`）。
- 广告面审计：19 类广告 × 6 族。
- 旁路审计：枚举 17 条「广告请求绕开整个插件」的路径。
- App 覆盖率审计：拿 14 家上游黑名单反查 13 个 App 插件。
- Loon 能力覆盖报表（175 条，探测真实用法；69 已用 / 40 可用未用 / 50 判死 / 12 不适用 / 4 未文档化）。
