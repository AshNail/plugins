# 私有多端配置与验证状态

本项目按私有自用维护。源码、设备凭据、生成产物分离：节点口令、订阅链接和 CA 不进入 Git；生成器仍拒绝写入仓库并使用 0600 权限。`package.json` 的 `private` 不代表 GitHub 仓库已私有化。

## 生成入口

`tools/make-private-config.py --lcf <设备导出文件> --platform <平台> --out <仓库外路径>`

| 平台 | 当前生成行为 | 真机状态 |
| --- | --- | --- |
| ios | 移动端基线；与 ipados 当前共用候选插件集 | 未验证 |
| ipados | 独立参数入口；尚未实现完整能力清单筛选 | 未验证 |
| macos | 排除 soda、douyin、Biliverse ADBlock | 当前运行配置完成基础网络验证；新生成产物未验收 |
| tvos | 仅保留 ads 插件；去除主配置 MITM、Rewrite、Script、Remote Script、IP Rewrite | 未验证；ads 的远程依赖仍需交付 |
| all | 保留兼容入口，不代表每个平台都可用 | 不推荐作为设备验收对象 |

所有平台移除 kelee.one 插件，`--keep-lcf-plugins` 也不能恢复它们。TV 不保留导出文件的额外插件。其他平台的额外插件仍属于用户显式选择，尚未完成元数据与最低版本验证。

相同名称、相同值的节点、订阅、策略组定义去重；同名异值拒绝生成，不打印凭据。Host 保留大小写变体，以兼容 Mac 上 `fnos`/`FNOS` 的实际解析行为。

## 已验证与未验证

2026-11-04 当前 Mac 运行配置完成：国内外 HTTPS、完整订阅下载、fnos/FNOS SMB 协议响应；可莉插件引用从 47 个插件中移除 16 个。该结果不能替代生成器产物验收，更不能推及其他设备。

新生成器的配置合并与去重通过回归测试。`--keep-device-rules` 显式保留设备完整 Rule 段，避免丢失 NAS、订阅获取例外及策略名称；不自动混合基线规则。2026-11-04 Mac 候选产物已实际加载并完成重连、国内外 HTTPS、订阅下载和 fnos/FNOS SMB 响应验证，未验证无缓存首次启动。

`--inline-native` 合并淘宝默认 Host 与广告过滤器默认域名规则，并移除两个远程引用；不启用可选 MITM、Rewrite 或脚本。合并具备重复执行与 Host 冲突测试，但不是通用插件打包器。Mac 已通过临时回环 TLS 探针确认淘宝测试域命中 127.0.0.1，广告过滤器测试域在 DNS 阶段被拒绝。正常淘宝登录入口返回 302，不代表下单支付流程已验收。

当前现网仍有四个异常资源。`--keep-device-plugins` 显式以设备插件清单为准，保留顺序和启停状态，再执行平台及退役来源过滤；与 `--keep-lcf-plugins` 同用时以设备清单模式为准，避免把平台过滤项加回。未指定时仍使用项目基线。2026-11-04 使用 `--platform macos --keep-device-rules --keep-device-plugins --inline-native` 预演，插件、规则、节点、订阅、策略组与现网顺序一致，Host 条目集合一致（25 插件、526 规则、21 Host）。这不是全文件等价或无缓存安装验证；部署前仍需审查其他段落差异。

## 私有交付边界

目前产物仍包含远程资源 URL，**不是离线完整包**。已有六个自建插件地址返回 404；不能因本地源码存在而声明设备上已生效。GitHub 仓库切为私有后，匿名 Raw URL 也不能作为交付方案。

离线交付需要逐端验证本地插件和脚本导入方式，再递归打包脚本、规则与必要资源。尚未验证前，不写入猜测的 file:// 地址，不注入应用缓存，不把仓库访问令牌放入 URL。

## 验收顺序

1. 构建、配置检查、来源与依赖检查、同名冲突和平台筛选测试。
2. 使用设备专属凭据生成仓库外产物，确认不会覆盖其他平台输出。
3. 核验插件与脚本实际加载，失败资源不能计入功能覆盖。
4. 真机验证 DNS、局域网、国内外分流、订阅冷启动、登录支付、推送和媒体。
5. MITM 按设备配置；TV 默认关闭。没有实际测试的平台保持“未验证”。
6. 保留前一版本及设备配置备份；回滚不依赖在线下载。
