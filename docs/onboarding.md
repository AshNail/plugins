# 新用户导览：从零到「导入即用」

> 适用对象：**什么都不懂、只想照着点一下就装好广告拦截 + 分流 + 科学上网的用户**。
> 不适用：已经会装的老手（直接看 `loon-max-config.md` 与 `device-checklist.md`）。

---

## 0. 先回答三个最常见的问题

**Q: 这个配置收费吗？**
配置本身免费、开源。你需要：
- 一台 Apple 设备（iPhone / iPad / Mac / Apple TV，系统尽量新，**Loon ≥ 3.5.2(996)**）
- **非中国区 Apple ID**，在 App Store 买断 **Loon（$7.99）**，它不自带节点
- 一个节点订阅（你自己的服务器／机场／"机场订阅链接"，形如 `https://xxx/subs/…`）

**Q: 导入之后，我需要自己配什么吗？**
不需要。一键导入会：装上 41 个广告/隐私拦截插件 → 接好国内分流（直连）与境外（代理） → 确保护定连接（银行/微信等不解密）→ 兜底直连。
你只需要：点一下导入按钮 → 再点一下「允许替换配置」→ 导入节点订阅 → 打开开关。全程 5 分钟。

**Q: 这个配置会不会泄露我的订阅 / 账号？**
不会。公开的 `configs/loon.conf` **不含任何节点、订阅链接、证书私钥、口令**，可以自由分发。
你的节点只存在于你自己的设备上。

## 1. 准备（1 分钟）

1. 确认设备是 iPhone / iPad / Mac / Apple TV，系统足够新
2. 准备一个**非中国区 Apple ID**（没有就注册一个美区/港区 ID，全程纯网页注册，不用信用卡）
3. App Store 搜索 **Loon**（Loon Lab 出品，图标是紫色 Q 气球），$7.99 买断
   - iOS / iPadOS / tvOS：进 App Store 直接买
   - Mac：Loon 4 for Mac 正在内测，以官网 <https://loonapp.org> 或 App Store 为准
4. 找一份节点订阅（你自己的服务器 / 机场都行，只要链接里是 Loon 能解析的节点，ss/vmess/vless/hy2 等都兼容）

## 2. 一键导入完整配置（1 分钟）

> 这一步**不需要**先有节点，纯做"去广告 + 国区直连"也能用。

在 iPhone / iPad / Mac 上**点这里**（或者把下面任意一行粘贴到浏览器里打开）：

```
https://www.nsloon.com/openloon/import?sub=https%3A%2F%2Fraw.githubusercontent.com%2FAshNail%2Fplugins%2Fmain%2Fconfigs%2Floon.conf
```

会发生什么（对号入座，不要跳过）：

1. 浏览器跳转到 **Loon App**（提示"在 Loon 中打开"）→ 点**打开**
2. Loon 弹窗：`导入资源` / `是否替换当前配置？` → 点**替换**（原配置被覆盖；重装可找回）
3. 等待几秒，配置下载完毕，Loon 主页变成新配置
4. 自动装上 **41 个插件 + 511 条规则**：应用列表里全是开着的、不需要逐个点开
   - 广告黑洞（`ads.plugin`）
   - 国内直连 / 国外代理分流
   - 银行 / 米家 / 京东人等统一只拦截广告，**不碰支付功能**
   - DoT / DoQ 加密 DNS 直连被替代/阻断，防广告插件被绕过

导入完成后：

1. 打开 Loon 首页 → 看右上角 **Loon 开关为开启**
2. 再看主页的 **Proxy 模式 / Filter 模式 / Direct 模式**
   - `Direct`：所有流量直连（只去广告，无法用代理，纯净模式）
   - `Filter` / `Rule`：按规则分流（**推荐**，国内直连、境外走 Proxy 组）
   - `Proxy`：所有流量全走 Proxy 组（纯外网场景）

> 对绝大多数中国用户：选 **Filter**，国内 APP 不绕路，海外 APP 走代理。

## 3. 导入你的订阅（代理节点）

没有节点，上一步只能"去广告 + 直连"，不能翻墙。这里补上：

**如果你有订阅链接（机场 / 自己买的 VPS）：**
1. Loon 首页 → **配置** → **添加订阅**
   - 类型：节点订阅
   - 名称：随便写（如「我的机场」）
   - 链接：粘贴订阅 URL
2. 保存 → Loon 自动下载节点 → 回到主页 → Proxy 切到你的订阅组（节点名一般是节点名如 `hy2-main-JP`，或者「我的机场」组）
3. 验证：打开 `speedtest-cn.com` 测国内网速（直连应该快），再打开 YouTube 看视频是否秒开 / 不缓冲（走了代理）

**如果你只是自己买了台服务器（比如 AWS 东京）：**
节点信息在你服务器上的面板（比如 `s-ui` 面板）里看，Loon 节点列表里手动添加即可。格式不看面板的话，也可以用整理好的配置：

1. 在服务器面板里复制你的订阅链接（本文示例那类 `https://xxx/sub/xxx`）
2. 或者保存到相册 / iCloud 文件里的 **配置 → 添加订阅**
3. 一步到位：订阅里的两个节点（比如东京 HY2 + REALITY）自动进入 Loon

**没有订阅？那就只能用 Direct（只能去广告）。**

## 4. 验证：你真的装好了吗（5 分钟）

按顺序快速过一遍：

- [ ] Loon 开关是开的
- [ ] 模式是 **Filter**（不是 Direct，否则 YouTube 打不开）
- [ ] 打开一个**淘宝页面**（淘宝广告图看不到，且商品图还是正常显示？）
- [ ] 打开一个**京东商品页**（`dns.jd.com` 等被放行，App 不崩溃）
- [ ] 关掉 Loon，App 走直连（上网慢但还是能上）
- [ ] 打开一个**激励广告**（比如汽水 / 抖音签到）：注意插件拦截的是**屏幕上看得见的广告**，不是领奖链路；如果连签到领奖都不行，禁用 `ads.plugin` 再试
- [ ] 银行 App（如招商银行、建行）：正常打开，**没有任何 MITM 解密**（本配置不解密银行 App）
- [ ] 看广告视频的 App（抖音/汽水）：开屏广告没了就成了；激励还想看就别加开屏拦截，或者改 `ads` 开关（见 FAQ）

## 5. 可选开关（需要的时候再开）

| 你遇到的场景 | 操作 |
|---|---|
| 带激励广告的 App 总是黑屏/闪退 | Loon → 配置 → 插件 → 找到 `ads.plugin` → 关掉，或只关「拦截激励」那一档 |
| 需要把流量全走代理（国外为主） | 首页 → 模式 → `Proxy` |
| 家里 Wi-Fi 想全局代理，外面走国内分流 | Loon → 配置 → Wi-Fi 设置 → 首页开关（或者 `ssid-trigger`，见 FAQ） |
| 想彻底不泄露 IPv6 | 改成 `ip-mode = v4-only`（默认 `prefer-v4`，有 AAAA 但没拒绝） |
| 想减少广告视频的卡顿提示 | 不要开 `doq-server`（日志里 5239 次尝试 5236 次失败） |

> 激励广告经常被建议直接关 `ads.plugin` ——它只拦截奖励任务页之外的广告；奖励链路不拦。

## 6. 常见问题（FAQ）

**Q: 导入后淘宝/京东彻底打不开了？**
A: 立刻检查三点：
1. Loon 开关模式是否是 **Filter**（不是 Proxy）
2. 银行/京东/米家相关条目已在公开配置里被放行（`dns.jd.com`, `janapi.jd.com` 等），如果你之前自定义过配置，可能覆盖了
   - 解决：Loon → 配置 → 重置为默认配置 / 重新导入本配置

**Q: 为什么 YouTube 打不开？**
A: 大概率是 **Proxy 组里选了 Direct 节点**。
   - 解决：Loon → 首页 → 点你的代理组 → 选到「hy2-main」之类节点 → 再测

**Q: 导入后 Loon 卡顿 / 卡顿严重？**
A: 重启 Loon App（iOS 双击 Home 清掉 Loon 再打开）。看 App 主页的 Data Usage；
   持续占用 CPU > 1 核，可能是某一个节点断流或插件死循环。去 **系统设置 → VPN & 设备管理 → Loon
   的连接日志** 里看报错。

**Q: 我的节点订阅里有 2 个节点，能同时用吗？**
A: 目前只用其中一个。想要负载均衡 / 自动选最低延迟：在 `[Proxy Group]` 里加
   `LoadBalance = load-balance,hy2-main-JP,vless-reality-JP,url=…,interval=600,algorithm = pcc`
   （或自己选 `url-test = 自动测速`）。双节点建议用 **url-test**，把第一个设成首选。

**Q: 银行 App 里有广告能关吗？**
A: 可以拦截显示出来的广告（广告图片），但不要让 App 认为被篡改：
   - 招行 / 中行 / 建行等：公开配置只拦截广告 Host，**不解密**；如果广告仍然显示，说明它不是域名级广告，无解。

**Q: MITM（中间人解密）那个 CA 证书要装吗？**
A: 不需要。公开配置**没有驱动 App 解密**的私钥；汽水/抖音/银行全部只做 Host/Rule 层。除非你自装一些需要 MITM 的插件（如汽水的 field-level 清理）。
   - 装了 CA 之后，你看银行的 HTTPS 流量理论上 Loon 能看到（但完全可以拦截）；不装就是纯分流。

## 7. 更新 / 卸载 / 重装

**更新配置**（不需要卸载 App）：
```
loon://update?sub=all          # 更新全部订阅
```
或者浏览器打开上面的导入链接，重新导入（Loon 自动覆盖旧配置）。

**卸载**：
- 直接删除 Loon App 会留下 "配置遗留"。建议：
  1. 先在 Loon 里导出备份
  2. 删除 App 前在 **系统设置 → VPN** 关掉 Loon 的 VPN 条目
  3. 删除后再重新安装，导回/导入即可
- 只想禁用某些插件：配置 → 点击插件 → 关即可，**不需要删配置**

**重装回滚到最简单的配置**：
找一个"你能跑起来的"最小示例 `examples/loon.conf`，在仓库本地或者:
`https://raw.githubusercontent.com/AshNail/plugins/main/examples/loon.conf`，
导入它（只做广告拦截，无代理、无 MITM），看是否工作，再逐个加插件定位问题。
